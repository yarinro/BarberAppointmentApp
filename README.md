# Barber Appointment App

Barber Appointment App is an Android application developed in Java as part of an academic project.
The app allows users to manage barber appointments in a simple and user-friendly way.

## Features

* User-friendly Android interface
* Appointment booking flow
* Barber services display
* Date and time selection
* Basic appointment management
* Clean project structure using Java and Android components

## Technologies Used

* Java
* Android Studio
* XML Layouts
* Android SDK

## Project Purpose

The purpose of this project is to practice Android application development using Java, including working with activities, layouts, user input, navigation, and basic app logic.

## How to Run

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project in Android Studio.

3. Let Gradle sync the project.

4. Run the app on an Android emulator or a physical Android device.
